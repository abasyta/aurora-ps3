## ☁️ الطريق السهل: بناء سحابي بدون تثبيت أي شيء!

إذا لم يكن لديك وقت لتثبيت WSL، يمكن لـ **GitHub** بناء `aurora.pkg` لك مجاناً:

1. أنشئ حساباً مجانياً في [github.com](https://github.com) (دقيقة واحدة).
2. اضغط زر **＋** أعلى يمين الصفحة ← **New repository**.
3. الاسم: `aurora-ps3`، اختر **Public**، ثم **Create repository**.
4. في صفحة المستودع اختر **"uploading an existing file"** ثم اسحب **كل محتويات مجلد `aurora-ps3`** (من ويندوز) إلى منطقة الرفع — بما فيها مجلد `include` و`source` و`scripts` و`usrdir` والمجلد المخفي `.github` — وانتظر الرفع ثم اضغط **Commit changes**.
5. ستشتغل عملية البناء تلقائياً في تبويب **Actions** (5-10 دقائق؛ لو فُشيلت صورة الأدوات قد يبنيها من الصفر: ساعة تقريباً).
6. عند اكتمالها (علامة ✓) ادخل على **Actions ← أحدث تشغيل ← Artifacts** وحمّل **aurora-pkg** — داخل التحميل مضغوط ملف **`aurora.pkg`** جاهز!

ثم أتمم الخطوة 4 من الدليل أعلاه (فلاشة FAT32 → Package Manager).

## 🛠️ بناء البرنامج (خطوة بخطوة على ويندوز عبر WSL)

بناء برامج PS3 يحتاج بيئة لينكس. سنستخدم **WSL (لينكس داخل ويندوز)**.

### الخطوة 1: تثبيت WSL

1. افتح **PowerShell كمسؤول** (زر يمين على قائمة ابدأ → Terminal (Admin)).
2. نفّذ:
   ```powershell
   wsl --install -d Ubuntu-22.04
   ```
3. أعد تشغيل الجهاز عندما يطلب.
4. بعد الإقلاع، ستفتح نافذة أوبونتو — اختر اسم مستخدم وكلمة سر (الاسم بحروف صغيرة).

### الخطوة 2: انسخ المشروع إلى لينكس

من داخل نافذة Ubuntu:

```bash
cp -r "/mnt/c/Users/granola12/Documents/Default Project/aurora-ps3" ~/aurora-ps3
cd ~/aurora-ps3
```

### الخطوة 3: شغّل سكربت الإعداد

```bash
bash setup-wsl.sh
```

هذا السكربت يقوم بكل شيء تلقائياً:
1. تثبيت أدوات البناء (`build-essential`, `git`...).
2. بناء **مجموعة أدوات PS3** (ps3toolchain) — ⚠️ **يستغرق 1-3 ساعات** (مرّة واحدة فقط!).
3. بناء **ps3libraries** (cairo وfreetype وغيرها) — حوالي 30-60 دقيقة.
4. نسخ خط DejaVu ووضعه في الحزمة + توليد أيقونة البرنامج.
5. بناء **`aurora.pkg`** النهائي.

> 💡 بعد المرّة الأولى، إعادة البناء تصبح سريعة جداً: فقط `make pkg`.

### الخطوة 4: انقل PKG إلى السوني

بعد انتهاء البناء ستجد **`aurora.pkg`** في مجلد المشروع (`~/aurora-ps3/`).

انسخه إلى ويندوز:
```bash
cp aurora.pkg /mnt/c/Users/granola12/Documents/
```
ثم ضعه على فلاشة **FAT32** وأدخلها في السوني، ومن XMB:
**Package Manager → Install Package Files** (أو Install Package Files مباشرة في HEN).

## 📂 أين توضع الألعاب؟

البرنامج يفحص تلقائياً:

| المكان | النوع |
|--------|-------|
| `/dev_hdd0/GAMES` و `/dev_hdd0/GAMEZ` | نسخ احتياطية على الهارد الداخلي |
| `/dev_usb000/GAMES` ... `/dev_usb007/GAMES` | نسخ على فلاشة/هارد خارجي (وأيضاً `GAMEZ` و `PS3/GAMES`) |
| `/dev_hdd0/game/*` | ألعاب PKG مثبتة (تُفلتر تلقائياً للألعاب فقط) |
| مجلدات إضافية من `aurora.ini` | حسب إعداداتك |

كل نسخة يجب أن تحوي مجلد `PS3_GAME` داخلي وفيه `PARAM.SFO` (للعنوان) و`ICON0.PNG` (للغلاف).

### غلاف مفقود؟
إذا لم يوجد `ICON0.PNG` يرسم البرنامج لوحة متدرجة أنيقة تحمل معرّف اللعبة (مثل `BLUS31204`).

## 🚀 التشغيل المباشر للألعاب (webMAN MOD)

الإطلاق المباشر يعمل عبر **webMAN MOD** — المكوّن الأشهر على السوني المعدّل:

1. حمّل webMAN MOD من صفحته الرسمية (github.com/aldostools/webMAN-MOD).
2. ثبّت PKG خاصته من XMB.
3. بعد إعادة التشغيل، سيكون خادم webMAN يعمل في الخلفية على المنفذ 80.

عند الضغط على ✕ داخل أورورا: يرسل البرنامج طلب إطلاق إلى `http://127.0.0.1/play.ps3?path=...`
فيركّب webMAN اللعبة ويقلع بها مباشرة. 🎉

إذا لم يوجد webMAN، يعرض البرنامج رسالة توضح البدائل (multiMAN / IrisMAN / أيقونة اللعبة في XMB).

## ⚙️ ملف الإعدادات

`/dev_hdd0/game/AURORA001/USRDIR/aurora.ini` (عدّله عبر FTP — مثلاً خادم FTP الخاص بـ multiMAN أو webMAN):

```ini
extra_paths=/dev_bdvd        # مجلدات إضافية للفحص
webman_port=80               # منفذ webMAN MOD
# font=/path/to/font.ttf     # خط مخصص (اختياري)
```

بعد أي تعديل اضغط △ داخل البرنامج لإعادة الفحص.

## 🔧 حل المشاكل

| المشكلة | الحل |
|---------|------|
| `make: PSL1GHT not set` | افتح نافذة Ubuntu جديدة (السكربت أضاف المتغيرات لـ .bashrc) |
| خطأ في `cairo.h` غير موجود | لم تكتمل بناء ps3libraries — أعد خطوة 3/5 |
| `ppu-gcc: command not found` | لم يكتمل بناء toolchain — أعد خطوة 2/5، أو تحقق من `ls ~/ps3dev/ppu/bin` |
| الخط لا يظهر على الشاشة | انسخ `font.ttf` إلى `/dev_hdd0/game/AURORA001/USRDIR/` عبر FTP |
| PKG لا يثبت | تأكد أن الفلاشة FAT32 وأن التثبيت من Package Manager وليس مجلد عادي |
| أيقونة XMB عادية | استبدل `data/ICON0.PNG` بأيقونتك (320x176 PNG) وأعد `make pkg` |

أي خطأ تراه أثناء البناء — انسخ لي آخر 20 سطراً وسأصلحه فوراً.
